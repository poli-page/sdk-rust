This page tracks breaking changes between versions of the `poli-page` crate. Before `1.0.0`, a breaking change bumps the minor version. For the full per-release diff, see the [changelog](../changelog/), and for every before/after table, [`MIGRATION.md` in the repo](https://github.com/poli-page/sdk-rust/blob/main/MIGRATION.md).

## From 0.10.0 to 0.11.0

The SDK follows the retry policy and the error messages of the Poli Page API contract.

- **Retries**: `QUOTA_EXCEEDED`, `OVERAGE_CAP_EXCEEDED` (429) and `STORAGE_ACCESS_DENIED` (502) are no longer retried, and `is_retryable()` is `false` for them and for `DOWNLOAD_FAILED`, whatever the storage status. Handle the quota codes by `code()`.
- **Predicates** read the status: `is_auth_error()` 401/403 (a download refused with 403 included), `is_rate_limit_error()` 429, `is_validation_error()` 400 only (a 422 `BadRequest` no longer counts).
- **Messages**: the SDK-side messages are the specification's exact texts (`apiKey is required`, `Network request failed`, `Request timed out after <ms>ms`, `Request was aborted`, `Failed to download PDF: HTTP <status>`, `Failed to download PDF: network error`, `HTTP <status>`), and the `Display` of those variants. Match `code()`, not messages; `Error::message()` gives the bare message.
- **`source` field**: the API-status variants carry `source: Option<Box<dyn Error + Send + Sync>>`; add `source: None` where you build one.
- **Enums**: `PageFormat`, `Orientation` and `ThumbnailFormat` keep an unknown value as `Unknown(String)` and serialize it back unchanged; they are no longer `Copy` (clone or borrow).
- **`Retry-After`**: only digits and HTTP-dates are read, clamped to 30 s.
- **Injected client**: the SDK `timeout` bounds the whole attempt, body included; build an injected `reqwest::Client` with `.retry(reqwest::retry::never())`.

## From 0.9.x to 0.10.0

The API moved from template versions to environments. An API key belongs to one environment, and a render uses the project's copy published in that environment.

- **API keys**: a key is `pp_{env}_` followed by 32 lowercase hex characters (`pp_sandbox_…`, `pp_live_…`). The `pp_test_` and `pp_sa_` prefixes are gone: replace a `pp_test_` key with a `pp_sandbox_` key.
- **Render input**: `ProjectModeInput` is renamed `RenderInput` and is the only render input. Drop its `version` field: there is no version to pick. `DocumentDescriptor::version` is removed too.
- **Preview and inline HTML**: `render.preview`, `PreviewResult`, `InlineModeInput` and the old `RenderInput` enum are removed. Try a template or raw HTML in the playground at [play.poli.page](https://play.poli.page). `documents.preview(id)` stays.
- **Environments**: `DocumentDescriptor::environment` is a `String` with any environment name; the `Environment` enum is removed.
- **Thumbnails**: `documents.thumbnails(id, options)` takes `Option<ThumbnailOptions>`, and `ThumbnailOptions::new()` takes no argument (`.width(n)` sets the width). An omitted `format` gives JPEG, the API's default (0.9.0 documented PNG): set `format: Some(ThumbnailFormat::Png)` to get PNG. `ThumbnailFormat::Webp` is new; the enum is not `#[non_exhaustive]`, so an exhaustive `match` on it needs a `Webp` arm.
- **Error codes**: the version codes, `MISSING_PROJECT_OR_TEMPLATE`, `GONE` (now `410 DOCUMENT_GONE`) and `PAYMENT_REQUIRED` (now `403 ORGANIZATION_PAYMENT_GRACE`) are removed. `PROJECT_NOT_FOUND`, `PROJECT_NOT_IN_ENVIRONMENT`, `TEMPLATE_NOT_FOUND`, `PUBLISH_IN_PROGRESS` and others are new; see [Errors](../../production/errors/).

## 0.9.0

The first release of the Rust SDK on crates.io: no migration needed.

## Example

```rust
use poli_page::{PoliPage, RenderInput};
use serde_json::json;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = PoliPage::new(std::env::var("POLI_PAGE_API_KEY")?)?;

    // 0.9.x took ProjectModeInput with a `version`; 0.10.0 has neither.
    let pdf = client.render.pdf(RenderInput {
        project: "getting-started".into(),
        template: "welcome".into(),
        data: json!({ "name": "SDK Demo" }),
        ..Default::default()
    }).await?;

    std::fs::write("welcome.pdf", &pdf)?;
    Ok(())
}
```
