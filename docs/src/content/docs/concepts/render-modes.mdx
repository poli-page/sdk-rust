---
title: Render input
description: RenderInput names a published template by its project and template slugs; it is the only input of every render method.
---

The Rust SDK describes what to render with one struct, `RenderInput`: a template of a stored project, named by its `project` and `template` slugs, plus the `data` that fills it. It is the input of every render method: `render.pdf`, `render.pdf_stream`, `render.document` and the `render_to_file` helper.

## RenderInput

```rust
use poli_page::RenderInput;
use serde_json::json;

let pdf = client.render.pdf(RenderInput {
    project: "billing".into(),
    template: "invoice".into(),
    data: json!({ "invoiceNumber": "INV-001", "total": 1280 }),
    ..Default::default()
}).await?;
```

`project`, `template` and `data` are required by the API. `RenderInput::default()` sets `data` to JSON `null`, so always set it; `json!({})` is sent as `{}`. The optional `format`, `orientation`, `locale` and `metadata` fields are left out of the request when `None`. `idempotency_key` is sent as the `Idempotency-Key` header and `timeout` overrides the per-attempt timeout; neither is part of the request body.

## Environments, not versions

There is no version to pick. A render uses the project's copy published in the API key's environment: a `pp_sandbox_…` key renders what is published in `sandbox`. To render your own templates, publish the project to the key's environment.

The API has no preview of a template and no inline-HTML rendering. To try a template or raw HTML without an API key, use the playground at [play.poli.page](https://play.poli.page). `documents.preview(id)` still returns the stored HTML of a document you already rendered.

## Example

```rust
use poli_page::{PoliPage, RenderInput};
use serde_json::json;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = PoliPage::new(std::env::var("POLI_PAGE_API_KEY")?)?;

    let doc = client.render.document(RenderInput {
        project: "getting-started".into(),
        template: "welcome".into(),
        data: json!({ "name": "SDK Demo" }),
        ..Default::default()
    }).await?;
    println!("rendered in {}", doc.environment);

    Ok(())
}
```
